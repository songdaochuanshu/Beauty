# Beauty

## 简体中文

### 项目概述

Beauty 是一个基于现代 Web 技术栈构建的艺术感瀑布流图片展示应用。它旨在提供一个流畅、美观且响应式的图片浏览体验，通过无限滚动加载来自 [Picsum Photos](https://picsum.photos/) 的高质量图片。项目采用了最新的 React 18、TypeScript、Vite 5 和 Tailwind CSS，并结合 Framer Motion 实现了优雅的动画效果，为用户带来沉浸式的视觉享受。

### 主要特性

*   **艺术感瀑布流布局**：图片以动态、错落有致的方式呈现，充分利用屏幕空间，提升视觉美感。
*   **无限滚动加载**：当用户滚动到页面底部时，自动加载更多图片，提供无缝的浏览体验。
*   **图片放大预览**：点击图片可进入全屏预览模式，支持查看图片详情并提供关闭按钮。
*   **响应式设计**：完美适应不同尺寸的设备，从桌面到移动端都能提供一致的用户体验。
*   **现代技术栈**：采用 React 18、TypeScript、Vite 5、Tailwind CSS 和 Framer Motion，确保项目的高性能、可维护性和开发效率。
*   **优雅的动画效果**：图片加载、显示和放大等交互都伴随着流畅自然的动画，增强用户体验。

### 技术栈

| 技术         | 描述                                     |
| :----------- | :--------------------------------------- |
| **React 18** | 用于构建用户界面的声明式、高效、灵活的 JavaScript 库。 |
| **TypeScript** | JavaScript 的超集，提供静态类型检查，增强代码可维护性。 |
| **Vite 5**   | 极速的下一代前端开发与构建工具。         |
| **Tailwind CSS** | 实用至上的 CSS 框架，快速构建自定义设计。 |
| **Framer Motion** | 生产级的 React 动画库，实现流畅的 UI 动画。 |

### 快速开始

#### 环境要求

请确保您的开发环境已安装 Node.js (推荐 v18+) 和 npm 或 yarn。

#### 安装依赖

```bash
cd Beauty
npm install
# 或者
yarn install
```

#### 运行项目

```bash
npm run dev
# 或者
yarn dev
```

项目将在本地开发服务器上运行，通常是 `http://localhost:5173`。

#### 构建项目

```bash
npm run build
# 或者
yarn build
```

构建后的文件将输出到 `dist` 目录。

## English

### Project Overview

Beauty is an aesthetically pleasing waterfall layout image display application built with a modern web technology stack. It aims to provide a smooth, beautiful, and responsive image browsing experience by infinitely loading high-quality images from [Picsum Photos](https://picsum.photos/). The project leverages the latest React 18, TypeScript, Vite 5, and Tailwind CSS, combined with Framer Motion for elegant animations, offering users an immersive visual feast.

### Key Features

*   **Artistic Waterfall Layout**: Images are presented dynamically and staggered, making full use of screen space to enhance visual appeal.
*   **Infinite Scroll Loading**: Automatically loads more images as the user scrolls to the bottom of the page, providing a seamless browsing experience.
*   **Image Enlargement Preview**: Click on an image to enter full-screen preview mode, supporting detailed viewing and providing a close button.
*   **Responsive Design**: Perfectly adapts to various device sizes, offering a consistent user experience from desktop to mobile.
*   **Modern Tech Stack**: Utilizes React 18, TypeScript, Vite 5, Tailwind CSS, and Framer Motion, ensuring high performance, maintainability, and development efficiency.
*   **Elegant Animations**: Image loading, display, and enlargement interactions are accompanied by fluid and natural animations, enhancing the user experience.

### Technology Stack

| Technology         | Description                                                              |
| :----------------- | :----------------------------------------------------------------------- |
| **React 18**       | A declarative, efficient, and flexible JavaScript library for building user interfaces. |
| **TypeScript**     | A superset of JavaScript that adds static type definitions, enhancing code maintainability. |
| **Vite 5**         | A next-generation frontend tooling that provides an extremely fast development experience. |
| **Tailwind CSS**   | A utility-first CSS framework for rapidly building custom designs.        |
| **Framer Motion**  | A production-ready React animation library to power fluid UI animations. |

### Getting Started

Please ensure you have Node.js (v18+ recommended) and npm or yarn installed in your development environment.

```bash
cd Beauty

# or
yarn install
```

#### Running the Project

```bash
npm run dev
# or
yarn dev
```

```bash
# or
yarn build
```
